# ADR-0012: სტეკი — სტატიკური საიტი, ფასების შემოწმება GitHub Actions-ში, ჰოსტინგი GitHub Pages

## კონტექსტი

[[SPEC-0001-fuel-prices-map]] ითხოვს ერთ გვერდს რუკით, ★-ის ბარათით და ფასების ცხრილით, ფასების ავტომატურ შემოწმებას ყოველ 3 საათში (REQ-006), სარწმუნოობის შემოწმებას (REQ-007) და იმას, რომ სტუმრის კოორდინატები ტელეფონიდან არ გავიდეს (REQ-010). [[intent]] §5 ითხოვს უფასო ჰოსტინგს და უფასო ლიმიტს. რეპოზიტორია `VazhaG/VazhaG` საჯაროა (GitHub, 2026-10-30).

ოფიციალური წყაროები, შემოწმებული 2026-10-30:
- GitHub Actions: საჯარო რეპოზიტორიაში სტანდარტული GitHub-ის runner-ები უფასოა; განრიგით გაშვების მინიმალური ინტერვალი 5 წუთია; განრიგი შეიძლება დაგვიანდეს, განსაკუთრებით საათის დასაწყისში, და დიდი დატვირთვისას ზოგი გაშვება შეიძლება გამოტოვდეს; საჯარო რეპოზიტორიაში განრიგი ავტომატურად ითიშება, თუ 60 დღე აქტივობა არ ყოფილა; განრიგი მხოლოდ ძირითად ტოტზე ეშვება (docs.github.com — „Events that trigger workflows“, „About billing for GitHub Actions“).
- GitHub Pages: საიტი ≤ 1 GB, რბილი ლიმიტი 100 GB ტრაფიკი თვეში; არ არის განკუთვნილი ონლაინ ბიზნესისთვის, ელ-კომერციისთვის ან SaaS-ისთვის (docs.github.com — „GitHub Pages limits“).
- OpenStreetMap-ის ფილების სერვერი (tile.openstreetmap.org): უფასოა, მაგრამ შეზღუდული სიმძლავრით; სავალდებულოა ხილული ატრიბუცია („© OpenStreetMap contributors“), სწორი Referer, ქეშირება; აკრძალულია ფილების მასობრივი ჩამოტვირთვა და „მძიმე“ გამოყენება (operations.osmfoundation.org/policies/tiles).

## გადაწყვეტილება

მფლობელმა აირჩია ვარიანტი (ა) — **მფლობელი**, 2026-10-30.

1. **საიტი** — უბრალო HTML, CSS და JavaScript, აგების ეტაპის გარეშე, საქაღალდეში `site/`. რუკა — Leaflet (ღია ბიბლიოთეკა), რომლის ფაილები `site/`-შივე დევს (არა CDN-იდან — ასე სტუმრის ბრაუზერი მესამე მხარეს მხოლოდ რუკის ფილებს სთხოვს). ფილები — tile.openstreetmap.org, ხილული ატრიბუციით. ★-ის ანგარიში, ფასის ასაკი და საწვავის ფილტრი ბრაუზერში სრულდება, სტუმრის კოორდინატები ქსელში არ იგზავნება (REQ-010).
2. **ფასების შემოწმება** — Python-ის პროგრამა საქაღალდეში `scraper/`, ერთი მოდული თითო კომპანიაზე (Wissol — ცალკე, ერთი პარამეტრით გამოსართავი, [[SPEC-0001-fuel-prices-map]] §7). ეშვება GitHub Actions-ის განრიგით ყოველ 3 საათში, საათის დასაწყისის გარეშე (მაგ. `17 */3 * * *`). წერს `site/data/prices.json`-სა და `site/data/stations.json`-ს, თითოეულ ფასს — წყაროთი და დროით; სარწმუნოობას ამოწმებს წინა ფაილთან შედარებით (REQ-007). ფაილი commit-ით იწერება მხოლოდ მაშინ, როცა შეიცვალა.
3. **ჰოსტინგი** — GitHub Pages, ძირითადი ტოტიდან, GitHub Actions-ის workflow-ით; მისამართი — `https://vazhag.github.io/VazhaG/` (საკუთარი დომენი — მოგვიანებით, [[intent]] §4).
4. **სადგურების კოორდინატები** — კომპანიების სადგურების გვერდებიდან; სადაც კოორდინატები არ არის — OpenStreetMap-ის ღია მონაცემებიდან (ODbL ლიცენზია, ატრიბუციით); ზუსტი წყარო თითო კომპანიაზე — მე-4 ეტაპის პირველი ამოცანა, ჩაიწერება [[fuel-price-sources]]-ში.
5. **ხუთი ბრძანება** (ჯერ გაუშვებელი — გეგმის პირველი ამოცანა თითოეულს ერთხელ უშვებს; განსხვავება — გეგმის `## გადახრები`-ში). Python-ის ვირტუალური გარემო: `bash .claude/hooks/py.sh -m venv .venv`; `{venv_python}` — Windows-ზე `.venv/Scripts/python`, macOS/Linux-ზე `.venv/bin/python`.

| ნაბიჯი | ბრძანება |
|---|---|
| install | `{venv_python} -m pip install pytest djlint ruff playwright beautifulsoup4`, შემდეგ `{venv_python} -m playwright install chromium` |
| run (local) | `bash .claude/hooks/py.sh -m http.server 8000 --bind 127.0.0.1 --directory site` |
| lint | `{venv_python} -m djlint site --lint` და `{venv_python} -m ruff check scraper tests` |
| test | `{venv_python} -m pytest -q` (`tests/`: scraper-ის unit-ტესტები და ბრაუზერის ტესტები Playwright-ით — მათ შორის ★-ისა და ასაკის JavaScript-ის ლოგიკა რეალურ ბრაუზერში) |
| show | ბრაუზერში `http://127.0.0.1:8000`; გამოქვეყნების შემდეგ — `https://vazhag.github.io/VazhaG/` |

Node არ სჭირდება. ყოველი დაყენება — მფლობელის „კი“-თ.

## განხილული ალტერნატივები

- **(ბ) Cloudflare Pages + განრიგით გაშვება Cloudflare-ზე** — ცალკე ანგარიში და მეორე პლატფორმა; უფასო ლიმიტები არ შემოწმებულა. არ ავირჩიეთ: პროექტი უკვე GitHub-ზეა და (ა) იგივეს უფასოდ აკეთებს.
- **(გ) Astro ან Vite + React** — Node, აგების ეტაპი და მეტი ნაწილი ერთი გვერდისთვის; მფლობელს საიტის შეცვლა გაუჭირდება ([[docs/guides/website]] §2). არ ავირჩიეთ.
- **რუკის ფასიანი ან გასაღებიანი მომწოდებელი** (Google Maps, Mapbox) — API-გასაღები და ბილინგი; პირველ ვერსიას არ სჭირდება.

## შედეგები

- **+** ღირებულება — 0: ჰოსტინგი, განრიგი და რუკა უფასოა ზემოთ ჩამოთვლილ ლიმიტებში; ახალი ანგარიში არ სჭირდება.
- **+** ყველაფერი ერთ რეპოზიტორიაშია და ჩანს: ყოველი ფასის ცვლილება commit-ია თავისი თარიღით.
- **+** სტუმრის კოორდინატები სერვერამდე არ აღწევს — სერვერული ნაწილი საერთოდ არ არის.
- **−** განრიგი შეიძლება დაგვიანდეს ან გამოტოვდეს — მოძველების წესი (48 სთ / 7 დღე) ამას ფარავს.
- **−** 60 დღე აქტივობის გარეშე განრიგი ითიშება; თუ ფასები 60 დღე არ შეიცვალა, commit არ იქნება — საჭიროა ან მფლობელის ხელით ჩართვა, ან ყოველთვიური „ცოცხალია“ ჩანაწერი (გადაწყდება გეგმაში).
- **−** OpenStreetMap-ის ფილების სერვერი დიდ ტრაფიკს არ ითმენს — თუ საიტი პოპულარული გახდა, საჭირო იქნება სხვა მომწოდებელი (ახალი ADR).
- **−** განრიგი მხოლოდ ძირითად ტოტზე ეშვება: ავტომატური განახლება მაშინ დაიწყება, როცა სამუშაო ტოტი ძირითადში გაერთიანდება (მფლობელის გადაწყვეტილება).
- **−** კომპანიის საიტის ფორმის ცვლილება მის მოდულს ტეხს — REQ-007 და AC-005 ძველ ფასს იცავს, შეცდომა კი workflow-ის ჩანაწერში ჩანს.

## დადასტურება

- `gate.py`-ის `lint` და `unit` gate-ები ზემოთ მოცემული ბრძანებებით ჩაირთვება მე-4 ეტაპის დასაწყისში (მფლობელის „კი“-თ, `tools/gates/gates.toml`), თითოეული ერთხელ განზრახ გაფუჭებით შემოწმდება, რომ წითლდება.
- [[SPEC-0001-fuel-prices-map]]-ის AC-001…AC-010 — `pytest`-ით (Playwright-ის ბრაუზერის ტესტები AC-001, AC-003, AC-009, AC-010-ისთვის).
- workflow-ის პირველი ნამდვილი გაშვების შემდეგ `site/data/prices.json` შეიცავს მინიმუმ ერთი კომპანიის ფასს წყაროთი და დროით; მფლობელი ტელეფონზე ხსნის `https://vazhag.github.io/VazhaG/`-ს (მე-5 ეტაპი).
