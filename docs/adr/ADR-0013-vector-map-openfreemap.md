# ADR-0013: სტეკი — სტატიკური საიტი, Google-ის მსგავსი ვექტორული რუკა, ფასების შემოწმება GitHub Actions-ში, ჰოსტინგი GitHub Pages

## კონტექსტი

[[ADR-0012-static-site-github-actions-pages]] (მფლობელი, 2026-10-30) პროექტის სტეკს ადგენს: სტატიკური საიტი Leaflet-ითა და OpenStreetMap-ის ფილებით (რუკის კვადრატული სურათებით), ფასების შემოწმება Python-ით GitHub Actions-ში, ჰოსტინგი GitHub Pages-ზე. დამტკიცებული ADR არ იცვლება — ცვლილებისთვის ახალი ADR იწერება, რომელიც ძველს ცვლის. ეს ADR მთლიანად ჩაანაცვლებს ADR-0012-ს: მისი ყველა პუნქტი აქ ხელახლა წერია, და იცვლება მხოლოდ რუკის ფონი (პირველი პუნქტი).

მიზეზი: მფლობელს 2026-11-09-ს მაკეტები ეჩვენა და მწვანე რუკა არ მოეწონა — „არ მომწონს მწვანე და მინდა დამესგავსოს გუგლ მაპის სტილის ვიზუალს“. მან ორი გზა ნახა: დღევანდელი რუკა გაფერმკრთალებული მწვანით (ორი სურათი) და ახალი, ვექტორული რუკა სამ სტილში — „liberty“, „positron“ და „dark“ (ბოლო სამი სურათი, მხოლოდ რუკა). მისი პასუხი: „ბოლო 3 იყოს რაც გავს გუგლს“ (**მფლობელი**, 2026-11-09). ეს ასე წავიკითხეთ: ვექტორული რუკა, ნათელ რეჟიმში ის სტილი, რომელიც Google-ს ჰგავს („liberty“), მუქში — „dark“ (**ჰიპოთეზა** — Claude-ის წაკითხვა; მფლობელმა შემდეგ ერთად ნახა ღილაკები, ხატულები და ეს რუკა). ვექტორული რუკა ბრაუზერში თავად იხატება, ამიტომ გზების, პარკებისა და წყლის ფერები და წარწერების ენა ცალ-ცალკე წყდება.

ფაქტები — [[map-providers]] (ოფიციალური გვერდები და npm-ის რეესტრი, 2026-11-09): OpenFreeMap უფასოა, გასაღებისა და ლიმიტის გარეშე, კომერციულადაც; გარანტია არ აქვს და შეიძლება ნებისმიერ დროს შეწყდეს; მისი სტილი, შრიფტები, ხატულები და ფილები ერთი მისამართიდან მოდის — `https://tiles.openfreemap.org`. MapLibre GL JS — BSD-3-Clause, ხატავს WebGL-ით (ბრაუზერის გრაფიკული შესაძლებლობით). Leaflet-თან ხიდი `@maplibre/maplibre-gl-leaflet` — ISC.

ADR-0012-ის ფაქტები (ოფიციალური წყაროები, შემოწმებული 2026-10-30; ხელახლა არ შემოწმებულა):
- GitHub Actions: საჯარო რეპოზიტორიაში სტანდარტული runner-ები უფასოა; განრიგის მინიმალური ინტერვალი 5 წუთია; განრიგი შეიძლება დაგვიანდეს, განსაკუთრებით საათის დასაწყისში, და დიდი დატვირთვისას ზოგი გაშვება შეიძლება გამოტოვდეს; საჯარო რეპოზიტორიაში განრიგი ავტომატურად ითიშება, თუ 60 დღე აქტივობა არ ყოფილა; განრიგი მხოლოდ ძირითად ტოტზე ეშვება (docs.github.com — „Events that trigger workflows“, „About billing for GitHub Actions“).
- GitHub Pages: საიტი ≤ 1 GB, რბილი ლიმიტი 100 GB ტრაფიკი თვეში; არ არის განკუთვნილი ონლაინ ბიზნესისთვის, ელ-კომერციისთვის ან SaaS-ისთვის (docs.github.com — „GitHub Pages limits“).
- OpenStreetMap-ის ფილების სერვერი (tile.openstreetmap.org): უფასოა, მაგრამ შეზღუდული სიმძლავრით; სავალდებულოა ხილული ატრიბუცია, სწორი Referer, ქეშირება; აკრძალულია ფილების მასობრივი ჩამოტვირთვა და „მძიმე“ გამოყენება (operations.osmfoundation.org/policies/tiles).

## გადაწყვეტილება

1. **საიტი და რუკა** — უბრალო HTML, CSS და JavaScript, აგების ეტაპის გარეშე, საქაღალდეში `site/`. რუკა — Leaflet, რომლის ფაილები `site/`-შივე დევს (არა CDN-იდან). ★-ის ანგარიში, ფასის ასაკი და საწვავის ფილტრი ბრაუზერში სრულდება, სტუმრის კოორდინატები ქსელში არ იგზავნება ([[SPEC-0001-fuel-prices-map]] REQ-010). **ახალი — რუკის ფონი:**
   - OpenFreeMap-ის ვექტორული რუკა: ნათელ რეჟიმში სტილი „liberty“, მუქში „dark“; რეჟიმის გადართვისას სტილიც იცვლება. სტილის დეტალები (მაგ. წარწერების ენა) — სპეციფიკაციის საქმეა ([[SPEC-0006-glass-look]]), არა ახალი ADR.
   - ხატავს MapLibre GL JS, **Leaflet-ის შიგნით**, ხიდით `@maplibre/maplibre-gl-leaflet`: Leaflet რჩება, ლოგოების ხატულები, ★, ღილაკები, ფანჯრები და მათი ტესტები იმავე კოდზე რჩება — იცვლება მხოლოდ ერთი ფენა, რუკის ფონი.
   - ორივე ბიბლიოთეკა, Leaflet-ივით, `site/vendor/`-შია — ლიცენზიით და წყაროს ფაილით (ვერსია, მისამართი, SHA-256). **ვერსია ზუსტადაა მითითებული და გამოქვეყნებიდან მინიმუმ ორი კვირისაა** — ეს ამ ADR-ის საკუთარი წესია: ახალ ვერსიაში შეცდომა ან მავნე ცვლილება ჩვეულებრივ პირველ დღეებში ჩნდება. დღეს ამას აკმაყოფილებს MapLibre 6.16.0 (2026-10-25) და ხიდი 0.1.4 (2026-08-16). MapLibre-ს მე-6 ვერსია მხოლოდ ES მოდულია, ამიტომ პატარა ჩამტვირთავი მას ხიდისთვის გლობალურ სახელს (`maplibregl`) აძლევს.
   - რუკის ფონი გვერდს არ აყოვნებს: ★ ბარათი, სია და ხატულები მისი ბიბლიოთეკისა და სტილის მოლოდინის გარეშე იხატება; ბიბლიოთეკა მათ შემდეგ იტვირთება.
   - **სათადარიგო რუკა:** თუ ბრაუზერს WebGL არ აქვს, ბიბლიოთეკის ფაილი ვერ ჩაიტვირთა, სტილი შეცდომას აბრუნებს, ან რუკა 5 წამში ვერ ჩაიტვირთა (MapLibre-ის `load` მოვლენა — სტილი და პირველი ფილები; 5 წამი **ჰიპოთეზაა**), საიტი დღევანდელ OpenStreetMap-ის ფილებზე გადადის (tile.openstreetmap.org); იგივე ხდება, როცა რეჟიმის გადართვისას ახალი სტილი ვერ ჩაიტვირთა. მუქი რეჟიმის ფერის ფილტრი მხოლოდ ამ სათადარიგო ფილებზე მოქმედებს — ვექტორულ რუკაზე, ღილაკებსა და ხატულებზე არა.
   - **ატრიბუცია:** ვექტორულ რუკაზე „OpenFreeMap © OpenMapTiles Data from OpenStreetMap“ (MapLibre თავად ამატებს), სათადარიგოზე — „© OpenStreetMap contributors“.
   - **უსაფრთხოების წესი** (`site/index.html`-ის CSP) ხდება ზუსტად ასეთი — დღევანდელს ემატება მხოლოდ `blob:` (`img-src`), `https://tiles.openfreemap.org` (`connect-src`) და `worker-src 'self'` (MapLibre-ის worker-ის ფაილი ჩვენი მისამართიდანაა, `setWorkerUrl`-ით):
     `default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data: blob: https://tile.openstreetmap.org; connect-src 'self' https://tiles.openfreemap.org; worker-src 'self'; base-uri 'none'; form-action 'none'`
     `style-src 'self'` რჩება; MapLibre-ის მუშაობა ამ წესით ტესტით მტკიცდება (დადასტურება), არა დაშვებით.
2. **ფასების შემოწმება** — Python-ის პროგრამა საქაღალდეში `scraper/`, ერთი მოდული თითო კომპანიაზე (Wissol — ცალკე, ერთი პარამეტრით გამოსართავი, [[SPEC-0001-fuel-prices-map]] §7). ეშვება GitHub Actions-ის განრიგით ყოველ 3 საათში, საათის დასაწყისის გარეშე (მაგ. `17 */3 * * *`). წერს `site/data/prices.json`-სა და `site/data/stations.json`-ს, თითოეულ ფასს — წყაროთი და დროით; სარწმუნოობას ამოწმებს წინა ფაილთან შედარებით ([[SPEC-0001-fuel-prices-map]] REQ-007). ფაილი commit-ით იწერება მხოლოდ მაშინ, როცა შეიცვალა. *(ADR-0012-დან უცვლელად.)*
3. **ჰოსტინგი** — GitHub Pages, ძირითადი ტოტიდან, GitHub Actions-ის workflow-ით; მისამართი — `https://vazhag.github.io/VazhaG/` (საკუთარი დომენი — მოგვიანებით, [[intent]] §4). *(ADR-0012-დან უცვლელად.)*
4. **სადგურების კოორდინატები** — კომპანიების სადგურების გვერდებიდან; სადაც კოორდინატები არ არის — OpenStreetMap-ის ღია მონაცემებიდან (ODbL ლიცენზია, ატრიბუციით); წყარო თითო კომპანიაზე — [[fuel-price-sources]]-ში. *(ADR-0012-დან; იქ წყაროს ჩაწერა მე-4 ეტაპის ამოცანად ეწერა — ის უკვე შესრულებულია.)*
5. **ხუთი ბრძანება** (ADR-0012-ის ბრძანებები, ერთი განსხვავებით: install ახლა ფიქსირებული ვერსიების ფაილით მიმდინარეობს — `requirements-dev.txt`, როგორც ეს ფაილი თავად წერს). Python-ის ვირტუალური გარემო: `bash .claude/hooks/py.sh -m venv .venv`; `{venv_python}` — Windows-ზე `.venv/Scripts/python`, macOS/Linux-ზე `.venv/bin/python`. ბიბლიოთეკები `site/vendor/`-ში ხელით, ერთხელ ჩაიდება — Node არ სჭირდება. ყოველი დაყენება — მფლობელის „კი“-თ.

| ნაბიჯი | ბრძანება |
|---|---|
| install | `{venv_python} -m pip install -r requirements-dev.txt`, შემდეგ (სხვა მანქანაზე) `{venv_python} -m playwright install chromium` |
| run (local) | `bash .claude/hooks/py.sh -m http.server 8000 --bind 127.0.0.1 --directory site` |
| lint | `{venv_python} -m djlint site --lint` და `{venv_python} -m ruff check scraper tests` |
| test | `{venv_python} -m pytest -q` (`tests/`: scraper-ის unit-ტესტები და ბრაუზერის ტესტები Playwright-ით) |
| show | ბრაუზერში `http://127.0.0.1:8000`; გამოქვეყნების შემდეგ — `https://vazhag.github.io/VazhaG/` |

## განხილული ალტერნატივები

- **დღევანდელი რუკა ფერის ფილტრით** (მწვანის გაფერმკრთალება CSS-ით) — უფასო, ახალი ბიბლიოთეკის გარეშე, მფლობელმა მაკეტი ნახა (2026-11-09). არა: მთელ რუკას ერთნაირად აფერმკრთალებს — წყალსაც და გზებსაც — და Google-ს არ ჰგავს; მფლობელმა ვექტორული აირჩია.
- **CARTO Voyager** — Google-ის მსგავსი რასტრული ფილები. არა: 2026-11-09-ს ფილები წარწერით „API KEY REQUIRED“ მოვიდა.
- **Esri World Street Map** — არა: თბილისში ბეჟი და ნაკლებად დეტალურია, პირობები გადაუმოწმებელია.
- **Google Maps-ის ფილები** — არა: გასაღები, გადახდა და მკაცრი პირობები ([[map-providers]]).
- **მთლიანად MapLibre-ზე გადასვლა Leaflet-ის გარეშე** — უფრო სუფთაა, მაგრამ ხატულების, ★-ის, ღილაკების და მათი ათეულობით ტესტის თავიდან დაწერას ითხოვს; ხიდი იგივე იერს მცირე ცვლილებით იძლევა. შეიძლება მოგვიანებით, ცალკე ADR-ით.
- **Cloudflare Pages + განრიგით გაშვება Cloudflare-ზე** (ADR-0012-ის ვარიანტი ბ) — ცალკე ანგარიში და მეორე პლატფორმა. არა: პროექტი GitHub-ზეა და GitHub Pages იგივეს უფასოდ აკეთებს.
- **Astro ან Vite + React** (ADR-0012-ის ვარიანტი გ) — Node, აგების ეტაპი და მეტი ნაწილი ერთი გვერდისთვის; მფლობელს საიტის შეცვლა გაუჭირდება ([[docs/guides/website]] §2). არა.

## შედეგები
