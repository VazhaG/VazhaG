# PLAN-0005: იერსახე ნიმუშის ფოტოთი — აშენება

## 1. მიდგომა

სტეკი იგივეა ([[ADR-0012-static-site-github-actions-pages]]): სტატიკური საიტი, Leaflet და ჩვეულებრივი JavaScript-ი. ახალი პაკეტი არ ემატება, წამკითხველი (`scraper/`) და ლოგოების ფაილები არ იცვლება. ლოგოს წრე ერთი ფუნქციით იხატება — ხუთივე ადგილისთვის (რიგი, სია, ფილტრი, ★ ბარათი, რუკის ნიშანი) —, დღევანდელი ამოჭრის (`site/js/logos.js`-ის `mark`) და ერთი ჩამტვირთავის წესით, ამიტომ თითო ფაილი ისევ ერთხელ ითხოვება. ლოგოს გარეშე კომპანიის წრეც იგივე ფუნქციაა, ფერითა და ასოთი. ფერები CSS-ის ცვლადებითაა; რეჟიმის მექანიზმი (`data-theme`, `site/js/theme.js`) უცვლელია. ცხრილის ადგილას სია ჩნდება. ფილტრები ჩვეულებრივი ღილაკებითა და პანელებით შენდება — პანელში ნამდვილი ჩამრთველები და არჩევანის ღილაკებია, — ამიტომ კლავიატურა და ეკრანის წამკითხველი ბრაუზერის საკუთარ ქცევას იღებს. ფილტრი და რიგი (ან საწვავის ღილაკები) ერთ მდგომარეობას ცვლის: `state.off` და `state.fuel`. ყოველი ამოცანა წითელი ტესტით იწყება. [[SPEC-0005-look-from-reference-photo]] §3-ში ჩამოთვლილი ტესტები ჯერ ახალ მოთხოვნაზე წითლდება, მერე მწვანდება, და არცერთი არ იშლება. ყოველი ახალი წესი ერთხელ განზრახ ფუჭდება.
