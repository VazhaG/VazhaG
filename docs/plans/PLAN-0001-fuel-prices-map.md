# PLAN-0001: საწვავის ფასების რუკა — პირველი ვერსიის აშენება

## 1. მიდგომა

საიტი აშენდება [[ADR-0012-static-site-github-actions-pages]]-ის მიხედვით: უბრალო HTML/CSS/JavaScript `site/`-ში, Leaflet და OpenStreetMap-ის ფილები, ფასების წამკითხველი Python-პროგრამა `scraper/`-ში, ტესტები `tests/`-ში (pytest + Playwright). ყოველი ამოცანა ვერტიკალური ნაჭერია — ბოლოს მფლობელს რაღაც ახალი ეჩვენება გვერდზე. ტესტები კომპანიების საიტებს პირდაპირ არ მიმართავს: გამოიყენება ამ საიტების შენახული ასლები (`tests/fixtures/`), რომ gate-ები არ იყოს დამოკიდებული ინტერნეტზე. გვერდზე არასოდეს ჩანს გამოგონილი ფასი ან სადგური: საცდელი მონაცემი მხოლოდ ტესტებშია.
