# PLAN-0006: iOS-ის სტილი და Google-ის მსგავსი რუკა — აშენება

## 1. მიდგომა

საიტი არსებულია და ადგილზე იცვლება ([[ADR-0013-vector-map-openfreemap]]): უბრალო HTML, CSS და JavaScript, აგების ეტაპის გარეშე; Leaflet რჩება რუკის მასპინძლად. ჯერ ის შენდება, რაც მხოლოდ სტილს და ჩვენს კოდს ცვლის — მინა, ფერები, ხატულები, ★, ფორმები (T1–T4) —, და ყოველი ამოცანის ბოლოს მფლობელი ეკრანის სურათს ხედავს. მერე ბიბლიოთეკები საიტში ჩაიდება (T5), ვექტორული რუკა ერთ ფენად ჩაჯდება Leaflet-ში (T6) და მისი სათადარიგო გზა აშენდება (T7). ვექტორული რუკა ცალკე პატარა მოდულშია (`site/js/vectormap.js`), რომელიც ★ ბარათის, სიისა და ხატულების შემდეგ იტვირთება — ასე გვერდი მას არ ელოდება. ყოველი ამოცანა წითელი ტესტით იწყება; [[SPEC-0006-glass-look]] §3-ში ჩამოთვლილი ტესტები ჯერ ახალ მოთხოვნაზე წითლდება, მერე მწვანდება, და არცერთი არ იშლება. ყოველი ახალი წესი ერთხელ განზრახ ფუჭდება (`PYTHONDONTWRITEBYTECODE=1`, `__pycache__` წაშლილი — L-026; MISS = აკლია ტესტი — L-024). ბიბლიოთეკების დამატებაზე მფლობელის „კი“ — `/approve adr 0013` (2026-11-09; ADR-ის დამტკიცებისას ეს ცხადად ეთქვა).
