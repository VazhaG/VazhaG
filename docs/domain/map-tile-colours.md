# რუკის ფერები — რაზე დგას სადგურის ნიშანი

საიტის რუკა OpenStreetMap-ის სტანდარტული ფილებისგან შედგება (ფილა, tile — რუკის კვადრატული ნაწილი, სურათად). მუქ რეჟიმში იგივე ფილები საიტის საკუთარი ფერის ფილტრით ჩანს (`site/css/style.css`). აქ წერია, რა ფერებს ხედავს სტუმარი რუკაზე; ამ ფერებზე დგას სადგურის ნიშანი ([[SPEC-0005-look-from-reference-photo]] REQ-007). ეს გაზომვაა და არა OpenStreetMap-ის სტილის ოფიციალური აღწერა: სტილი შეიძლება შეიცვალოს, და მაშინ გაზომვა თავიდან უნდა გაკეთდეს.

## როგორ გაიზომა (2026-11-02, პირდაპირ)

- ბრაუზერი — Chromium (Playwright), ტელეფონის ეკრანი 375 × 812, პიქსელის სიმკვრივე 1. საიტი `site/` საქაღალდიდან გაეშვა ადგილზე, ფილები კი ნამდვილია, `tile.openstreetmap.org`-დან.
- მდებარეობა — თბილისის ცენტრი (41.7151, 44.8271). გვერდი მე-12 დონეზე იხსნება; მე-11-სა და მე-13-ზე კლავიატურით (− და +) გადავიდა.
- სადგურების ნიშნები, ფილტრები, საწვავის ღილაკები და რუკის ღილაკები დამალულია. იზომება რუკის ის ნაწილი, რომელსაც ქვედა ფურცელი არ ფარავს — 375 × 424 პიქსელი.
- ითვლება ყოველი პიქსელის ზუსტი ფერი. ქვემოთ — ფერები, რომლებიც ამ ფართობის მინიმუმ 0.1%-ს ფარავს (115–155 ფერი თითო ხედზე); კონტრასტი WCAG 2-ის ფორმულით ითვლება.
- გაზომვის სკრიპტი რეპოზიტორიაში არ ინახება; მეთოდი ზემოთ წერია, და გაზომვა ნებისმიერ დროს შეიძლება გამეორდეს.
