## როგორ იკითხება ფასი (2026-10-30, პირდაპირ)

- **ოთხივე საიტი პასუხობს** მოთხოვნას, რომელიც პროგრამას გულწრფელად ასახელებს (`VazhaG-fuel-prices/0.1 (+https://github.com/VazhaG/VazhaG)`): SOCAR, Rompetrol, Lukoil, Wissol — HTTP 200.
- **SOCAR** (https://www.sgp.ge/ge/): გვერდის მონაცემები Next.js-ის სკრიპტ-ნაწილებშია (`self.__next_f.push([1,"…"])`); მათში არის `"GetCurrentPrices"` → `Results` — თითო საწვავზე `FuelCode`, `FuelNameGeo`, `FuelNameEng`, `FuelUnitPrice` (სტანდარტული ფასი, ₾) და `ActionDate`. კოდები: SUPER, PREMIUM, EURREG, DIESEL, EURODSL, LPG, CNG. `ActionDate` „რა დროის მდგომარეობით“ დრო არ არის — 2023 წლის თარიღები დღევანდელ ფასებს ახლავს (მაგ. ნანო სუპერი 4.65 ₾, ActionDate 2023-09-23), თხევად აირს კი 2026-10-24 — ამიტომ SOCAR-ის ფასის ასაკი ჩვენი წაკითხვის დროიდან ითვლება ([[SPEC-0001-fuel-prices-map]] REQ-006). გვერდზე ხილული თარიღი არ არის. „ენერჯი ბარათის“ ფასი ცალკეა და არ იკითხება.
- **Rompetrol** (https://www.rompetrol.ge/): `<a id="pricelist">`-ის ქვეშ ერთი HTML ცხრილი „პროდუქტი | ლარი / ლ“ — efix სუპერი, efix ევრო პრემიუმი, efix ევრო რეგულარი, efix ევრო დიზელი, ევრო დიზელი; ყოველი მათგანის შემდეგ მწკრივი „- … (თვითმომსახურების სადგურებზე)“ — თვითმომსახურების ფასი (არ იკითხება). აირი ცხრილში არ არის.
- **Lukoil** (https://www.lukoil.ge/): ფასის ბარათები — სურათი alt="Price", მერე ფასი და სახელი ინგლისურად: Super Ecto 100, Super Ecto, Premium Avangard, Euro Regular, Euro Diesel. Super Ecto 100-ს ფასად 0.00 უწერია — ეს „ახლა არ იყიდება“-ად იკითხება და გამოტოვდება.
- **Wissol** (https://wissol.ge/ka/fuel-prices — ქართული გვერდი, ქართული სახელებით): მწკრივები `button.prices_row` — A1 სუპერი 100, ეკო სუპერი, ეკო პრემიუმი, ევრო რეგულარი, ეკო დიზელი, ევრო დიზელი, დიზელ ენერჯი, ვისოლ გაზი; სტანდარტული ფასი და, უმეტესობას, თვითმომსახურების ფასი (`is-self-service`, არ იკითხება).
- **Connect** (https://connect.com.ge/, 2026-10-31 — ჩვენს პროგრამას HTTP 200-ით პასუხობს): ფასის ბლოკი `div.fpc-…` — პირველი ბარათი (`.fpc-feat-name`; სტანდარტული ფასი `.fpc-feat-std`, თვითმომსახურების — `.fpc-feat-self`) და დანარჩენი ბარათები (`.fpc-card-name`, `.fpc-pstd`, `.fpc-pself`): სუპერი RON 98, პრემიუმი RON 96, რეგულარი RON 93, ევრო დიზელი 10PPM, დიზელი 10PPM. სტანდარტულისა და თვითმომსახურების ფასის რიგი ბარათებში სხვადასხვაა (სუპერში თვითმომსახურება პირველია), ამიტომ ფასი კლასით უნდა იკითხებოდეს და არა რიგით. აირი არ არის; ფასის თარიღი გვერდზე არ წერია. გვერდზე ყველაზე ხშირი ფერი #FFE900-ია (50-ჯერ) — ეს დაკვირვებაა და არა ფირმული ფერის ოფიციალური წყარო.
- **აირი:** SOCAR აქვეყნებს ორ ცალკე საწვავს — თხევადი აირი (LPG) და ბუნებრივი აირი (CNG); Wissol — ერთს, „ვისოლ გაზი“ (რომელი სახეობაა, გვერდზე არ წერია). ერთეული (ლიტრი თუ კუბური მეტრი) გვერდებზე არ წერია.
