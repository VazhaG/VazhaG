# SPEC-0004: კომპანიების ლოგოები და შავ-ნარინჯისფერი რეჟიმები გადამრთველით

## 1. პრობლემა და მიზანი

მფლობელმა გამოქვეყნებული საიტის ნახვის შემდეგ ითხოვა ([[intent]] §1, მეოთხე ნაბიჯი):

> „ვიზუალური ცვლილებები მჭირდება: 1. დასახელებების ნაცვლად კომპანიების ლოგოები გამოიტანე თავის ფერებში; 2. რუკაზე წერტილები ჩაანაცვალე კომპანიების პატარა ლოგოებით; 3. საიტის ძირითადი ფერები გადააწყე შავზე და ნარინჯისფერზე.“
> — **მფლობელი**, 2026-11-01

ეს სპეციფიკაცია ნიშნების რიგში კომპანიის სახელს მისი ლოგოთი ცვლის, რუკაზე ქალაქის მასშტაბიდან ასოიან წრეს — კომპანიის პატარა ნიშნით, საიტის ფერებს კი — შავითა და ნარინჯისფრით, ნათელ და მუქ რეჟიმში, რომელთა შორისაც სტუმარი გადამრთველით ირჩევს. ლოგოები [[intent]]-ის მიზანს G5 ემსახურება (კომპანიას ლოგოთი ცნობს); ფერები და გადამრთველი მფლობელის პირდაპირი მოთხოვნაა (§1, მეოთხე ნაბიჯი; QV2) და G1-სა და G2-ს იკითხვადობით ემსახურება. ლოგოები ჩნდება კომპანიების ნებართვის გარეშე, მფლობელის გადაწყვეტილებით — ხუთივე კომპანიისთვის (QV1; §8). „რეჟიმი“ აქ [[intent]] §5-ის „იერსახეა“. რომელ ადრინდელ წესებს ცვლის ეს სპეციფიკაცია, §3-ის ცხრილი ამბობს.

## 2. მომხმარებლები და სცენარები

1. **ლოგოთი ცნობა.** მძღოლი ★ ბარათის თავზე ნიშნების რიგში თავისი კომპანიის ლოგოს ცნობს, აჭერს მას და დანარჩენებს თიშავს — როგორც დღეს სახელიან ნიშანზე.
2. **რუკა.** ქალაქის მასშტაბზე სადგურები კომპანიების პატარა ნიშნებითაა: SOCAR-ის ცეცხლი, Rompetrol-ის ყვავილი, Lukoil-ის წითელი კვადრატი, Wissol-ის მწვანე წრე, Connect-ის ყვითელი სამკუთხედი. მთელი საქართველოს ხედით — ფერადი წერტილებით.
3. **მზე და ღამე.** მძღოლი დღისით ნათელ რეჟიმს ხედავს, ღამით გადამრთველით მუქზე გადადის, და მეორე დღეს საიტს ისევ მუქი რეჟიმით ნახავს — გახსნის პირველივე წამიდან.
4. **ცუდი დღე — კომპანია ლოგოს მოხსნას ითხოვს.** მფლობელი Claude-ს სთხოვს, Claude ლოგოს ფაილს და მის ჩანაწერს შლის, მფლობელი გაერთიანებაზე „კი“-ს ამბობს, და ერთ საათში ამ კომპანიის ნიშანი ისევ სახელიანია, ლოგოს ფაილი კი გამოქვეყნებულ საიტზე აღარ არის.
5. **ცუდი დღე — ლოგო არ გვაქვს ან არ იტვირთება.** მონაცემში ახალი კომპანია ჩნდება, ან ლოგოს ფაილი ვერ ჩამოიტვირთა: მისი ნიშანი სახელიანია, რუკაზე — ფერადი წრე ასოთი, დანარჩენები კი ლოგოებით ჩანს.
6. **ცუდი დღე — ბოროტი მონაცემი.** მონაცემში კომპანიაა უცნაური კოდით (`__proto__`, `../x`) ან სახელით, რომელშიც HTML წერია: მისთვის ლოგო არ ჩნდება, სახელი მხოლოდ ტექსტად ჩანს, და საიტი ამ კოდით არაფერს ითხოვს.

## 3. მოცულობა

- **შედის:** ხუთი კომპანიის ლოგოს ფაილი საიტის შიგნით და მათი სია კომპანიის კოდით; ლოგო ნიშნების რიგში; კომპანიის ნიშანი რუკაზე ქალაქის მასშტაბიდან; ორი რეჟიმი შავი და ნარინჯისფერი ფერებით; რეჟიმის გადამრთველი და მისი დამახსოვრება; სახელიანი ნიშანი, როცა ლოგო არ გამოდგება; ლოგოს მოხსნის წესი.
- **არ შედის:**
  - Gulf — მონაცემში არ არის ([[SPEC-0003-connect-stations-and-prices]] §3).
  - ლოგო ★ ბარათში, ფასების ცხრილსა და სადგურის ფანჯარაში — იქ კომპანია ისევ სახელითა და ფერის წერტილით ჩანს; მფლობელმა ლოგოები ნიშნების რიგსა და რუკაზე ითხოვა — **ჰიპოთეზა**.
  - რუკის ნიშნები ეკრანის წამკითხველისა და კლავიატურისთვის — დღესაც ასეა; სადგურის მონაცემი ცხრილსა და ★ ბარათშია.
  - განლაგების შეცვლა; ნებართვის წერილები — ცალკე ამოცანებია ([[todo]]).
- **რას ცვლის ადრინდელ სპეციფიკაციებში.** დანარჩენი წესები უცვლელია.

## 6. არაფუნქციური მოთხოვნები

- **უსაფრთხოება:** ლოგოები ჩვენივე, შემოწმებული ფაილებია (REQ-003, AC-004), რომლებიც სურათად (`<img>`) ჩანს; სურათის მისამართი მხოლოდ ჩვენი სიიდან მოდის, კომპანიის ზუსტი კოდით (REQ-003, AC-005); მონაცემიდან მოსული ტექსტი მხოლოდ ტექსტია ([[SPEC-0001-fuel-prices-map]] REQ-008).
- **სიჩქარე:** ლოგოები ≤ 300 კბ, თითო ფაილი ერთხელ იტვირთება, რუკის 516 ნიშანი იმავე ფაილებს იყენებს; ნელი ან ჩავარდნილი ლოგო ★ ბარათს არ აყოვნებს (AC-006, AC-010).
- **ხელმისაწვდომობა:** ლოგოიან ნიშანს სახელი აქვს; გამორთვა და არჩეული მდგომარეობა ფერის გარდა სხვა ნიშნითაც ჩანს (ხაზი, მსხვილი წარწერა); ნიშნის ჩარჩო და ფოკუსის რგოლი მინიმუმ 3 : 1; გადამრთველი ღილაკია, კლავიატურით მისაწვდომი, მუდმივი სახელითა და `aria-pressed`-ით; რუკის ნიშნები დეკორატიულია (§3).
- **ქართული ტექსტის ხარისხი:** ახალ ტექსტებს („მუქი რეჟიმი“, შენახვის წინადადება) Claude წერს (Sonnet-ის დონე ან უკეთესი), მფლობელი ასწორებს.

_ღია კითხვა აღარ არის._ QV1-ის ფარგლებზე — ფარავს თუ არა „ყველა ლოგო ახლავე“ Lukoil-ის ფაილს, რომელიც lukoil.ge-ზე სხვა საიტიდან ჩანს, და Wissol-ისა და Connect-ის პირობებს, რომლებიც მათი საიტის შინაარსის კოპირებას კრძალავს (§7) — მფლობელის პასუხია: „კი, ხუთივე ლოგო“ — **მფლობელი (დაეთანხმა რეკომენდაციას)**, 2026-11-01. ამიტომ REQ-001-ის ხუთივე ლოგო ჩანს; რისკი მფლობელისაა, ისევე როგორც ამ კომპანიების ფასების შემთხვევაში, და ლოგო კომპანიის მოთხოვნისთანავე მოიხსნება (REQ-004).
